# Reverse core boundary

Reverse Fusion keeps the installed enhanced `reverse-skill` as the route and
case authority. This directory records the ownership boundary and does not
vendor a second router. A future owned enhancement is added here only after a
specific capability gap has an Evidence pointer, a regression fixture and a
rollback commit.

The bridge invokes the native router in dry-run mode and stores only its route,
case and `decision_delta` pointers in this repository.
