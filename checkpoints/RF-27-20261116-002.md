## Windows JSON transport change

The actual Python pipe encoding is GBK on this machine. JSON previously emitted
unescaped Unicode, corrupting Chinese text when decoded as UTF-8 and failing on
characters outside the code page. Earlier external tests set `-X utf8`, which
masked this boundary. CLI JSON now uses standard ASCII Unicode escapes. The new
external-process test forces GBK, omits `-X utf8`, and round-trips both Chinese
and an emoji in the project path/hint through ASCII JSON. Files remain Unicode.
