标签收纳盒 — 使用说明

开始使用
1. 如果收到的是 ZIP 文件，请先右键“全部解压”。
2. 双击“启动.cmd”，浏览器会自动打开标签收纳盒。
3. 请保持启动窗口打开。如果浏览器没自动出现，打开 http://127.0.0.1:8877/ 。
4. 结束使用时，关闭启动窗口，或在窗口内按 Ctrl+C。

日常操作
填写名称、分类和数量，点击“添加条目”。分类不填会归入“未分类”。
数量须为 1 到 99 的整数；名称最多 32 个字符。同一分类里不能重复添加同名条目（英文字母不区分大小写）。
搜索框可以查找名称或分类；排序可选择“最近添加”或“按名称”。
底部显示当前搜索结果的条目数和总件数。
点“删除”移除单项；“清空全部”需要确认，取消不会删除。

数据保存
数据自动保存在当前浏览器中；刷新页面或关闭启动窗口不会清空。
请尽量一直使用同一个浏览器和 http://127.0.0.1:8877/ 地址。
换浏览器、使用隐私模式、清理网站数据或点“清空全部”会影响已保存数据。
数据不上传服务器，也不需要账号或互联网。原版与复刻版的浏览器数据各自独立，不自动迁移。

运行环境
此电脑已有 Python 3 和浏览器，直接双击即可。复制到其他电脑时，需要 Python 3 和现代浏览器。
启动提示地址被占用时，先关闭旧的启动窗口再试。
请通过启动文件使用，直接双击 index.html 可能受浏览器本地文件限制。

文件说明
index.html：界面和样式；core.mjs：数据与校验规则；page.mjs：界面操作；launch.py：仅在本机运行的启动器。
所有运行文件均在此文件夹中，不会调用原版或分析工具。
