## 本轮必须单独保留的证据

- `evidence/rf36/`保存本轮归档：实际provider调用、6条原生Evidence的导出/重启导入、
  Craft分析Project恢复/切换隔离/变化目标、MCP工具调用及本轮相关回归。具体文件与最终结果由当前状态和checkpoint索引。
- `release/verification.json`绑定本轮工程源码、实际回归日志及摘要；
  本机部署与远端新克隆结果必须来自同一版本，未执行的门不复制旧结果。
- RF-33完整应用与有限性能测量保留在`evidence/rf33/`；RF-34/RF-35原始记录仍保留。
  Codex历史全程约26.2分钟，Pi经历多次期限后恢复；这些记录不支持“任何任务都不卡顿”的宣传。

图片/3D、设备、商业引擎、外部账号与服务按职责合同的真实入口和条件使用。
资产生成需要实际producer、预算、密钥来源、输出边界与产物检查；宿主图片工具不能
替代3D。不能把真实适配缺口写成“只是缺key”，也不能把本地假provider检查写成已付费生成。
最终新增入口与真实操作状态统一记录在本轮合同、checkpoint和发布资格中。
