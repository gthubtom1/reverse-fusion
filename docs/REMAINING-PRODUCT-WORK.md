## 使用条件不等于工程缺口

共享核心已有Codex/Pi自然应用全程实跑；各宿主核入口、技能、工具、权限、cwd与生命周期，
不要求每个都登录模型跑同一应用。Codex自动MCP登记不扩张为Pi/Claude自动全局登记。
Windows x64是当前完整预编译分发；设备、商业工具、保护器、外部服务和其他平台按实际条件。

真实资产入口、provider执行条件与真实产物需分别核查；缺适配不能伪装为只缺账号，
本地假服务不能冒称付费生成。某个目标未决需求仍附着该目标，不能静默缩成小演示交付。
执行预算、进程清理和恢复已有检查；不宣称任意任务永不卡顿或任意软件必然复刻成功。
