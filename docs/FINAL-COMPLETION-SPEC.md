# Final v1 completion specification

This is a completion contract, not an independent current-state declaration.
Current release/audit status lives in `docs/CURRENT-STATE.md`; direct finite
checks and remaining boundaries live in `docs/FINAL-RELEASE-ACCEPTANCE.md` and
the latest checkpoint. The highest-level goal is `docs/PRODUCT-GOAL.md`.

The product is ready within its declared integration scope only when:

1. A remote fresh clone can create a repository-local venv, run contracts,
   plan/doctor/handoff, record the selected host and resolve a local route without
   an old receipt. Tested OS/shell scope must be distinguished from planned
   portability; unsupported provider runners stay explicit.
2. Reverse is the only route/case owner. Every local route has its descriptor,
   domain body and required support. The preserved enhanced-source inventory
   authenticates every retained or intentionally adapted file.
3. REA Evidence, bundles, comparison, unknowns and ledger pointers obey their
   official identity/closure contracts. An archive passes both file hashes and
   official Evidence parsing, with a real tamper rejection check.
4. Reconstruction spec/plan/tasks retain source references, frozen inputs and
   append-only converge. Analysis and normal development do not acquire these
   reconstruction requirements merely because the package is installed.
5. The current conversation's host can be the bounded single candidate writer;
   prepare, build, check, refine, summary and cleanup are observable. Session
   file checks alone are not business acceptance. Offline copy workers and an
   unqualified native Craft backend do not satisfy this real-writer gate.
6. WASM, Web/JavaScript, PE/.NET and APK/DEX representative chains retain their
   actual original/candidate observations, tasks, build/run status, comparison,
   proof and ledger. Finite runtime/static scopes and remaining unknown/open
   obligations are stated; full target equivalence is not inferred.
7. Correct behavior passes, intentionally wrong behavior fails, absent Evidence
   is unknown and missing providers are blocked/unsupported. Native exit errors,
   stale candidates, path escape and frozen-input drift fail closed.
8. Host-owned accounts/models stay host-owned. Optional CLI probes do not mutate
   known global config and do not turn historical sentinels into current health.
   Uncertain descendant cleanup is unknown/blocked.
9. Rollback, selective upstream review and persistent deployment/maintenance
   handoff are documented using mechanisms actually implemented.
10. Current docs, source manifests, tests, archive, checkpoint and GitHub remote
    agree. The audit ends after these finite checks; it does not expand into
    exhaustive execution of every future target variant.

A future target can still produce unknown, blocked or unsupported. It enters a
new case using the same contracts. This is separate from whether the delivered
repository has coherent deployment, ownership and recovery behavior.
