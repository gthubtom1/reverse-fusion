# Project-local Spec Kit layer

Spec Kit remains the official CLI. Reverse Fusion stores feature specifications,
source references and task contracts in the independent成果项目, while the
official REA Evidence and the original reverse case remain authoritative.

Use `spec_pointer()` from `reverse_fusion.adapters` to pass a feature name,
task IDs and source references into a bounded implementation batch. The pointer
does not copy an Evidence ledger or create a second route owner.
