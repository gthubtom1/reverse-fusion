# Spec Kit integration and historical qualification fixtures

Spec Kit remains the official CLI. Reverse Fusion stores feature specifications,
source references and task contracts in the independent成果项目, while the
official REA Evidence and the original reverse case remain authoritative.

Current reconstruction work must execute the installed official generated workflow
and actual native Craft handoff described in `docs/NATIVE-COMPONENTS.md` and
`docs/HOST-PROJECT-CONNECTION.md`. A `spec_pointer()` is only a reference helper,
not official phase execution or an implementation-readiness decision.

The tracked `console-project` and `reconstruction-*` trees below are historical
RF-06/RF-25 qualification projects. Their tasks, provider unknowns and generated
generic `.rf/commands` are preserved at the observed scope. They are not the
current product TODO list, installation steps or templates to copy into new
outcome projects. In particular, the old unchecked “attach real target” task
and Android runtime unknown do not require a new user sample to finish this
edition. Initialize official Spec in the actual outcome project for new work.
